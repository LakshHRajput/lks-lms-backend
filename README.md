# LKS LMS Backend

Backend API for LKS (Learning Knowledge Solution) LMS.

## Tech Stack

- Node.js
- Express.js
- TypeScript
- MySQL
- Prisma ORM
- JWT Authentication
- Zod
- bcrypt
- Helmet
- CORS

## Features

- Authentication
- JWT Access & Refresh Tokens
- Role-Based Access Control
- User Management
- Student Management
- Course Management
- Subject Management
- Chapter Management
- Video & Notes
- Tests & Questions
- Exam & Results
- Attendance
- Fees
- REST API

## User Roles

- Super Admin
- Admin
- Teacher
- Student
- Parent
